# Wick endpoint 1/12 certificate

**New theorem, three rows:** for q=X[c(|X|²-2)+P], EP=0, P independent of X, E|P|²=p, u=2|c|²+p, if .03<=u<=.0463 and p<=u/12, then

    C(q)² <= (563/2420)[B(u)-F(q)] < .24[B(u)-F(q)].

P may be any centered complex random variable with finite variance. For the original cubic problem take P to be a centered quadratic Gaussian form.

This enlarges the earlier p<=u/16 neighborhood. It does **not** prove the whole R26 family or Conjecture K.

`proof.md` contains the analytic justification. The numerical proof inputs are C(q0)²<=.09 Delta0 and Delta0>=5v² for pure Wick q0=sqrt(v/2)X(|X|²-2), uniformly over .027<=v<=.0463. Completed covers: peak 200 intervals, flank 189, upper 134. The tables contain 353 rigorous deterministic-shift kernel nodes per row.

The new smooth Abel kernel formulas, the periodic trapezoid error, interpolation remainder, radial Gauss error, and tails are explicit in the proof. This is a paper proof with Arb-supported scalar certificates; it has not been formalized in Lean.

## Replay

Requirements: Python 3, python-flint (tested 0.9.0), SciPy (tested 1.17.0). SciPy supplies only starting guesses for Gauss nodes; exact interval sign checks enclose the actual roots.

Run from the directory containing `wick_cert`:

    python wick_cert/check_constants.py
    python wick_cert/check_coverage.py
    OPENBLAS_NUM_THREADS=1 python wick_cert/check_wick_slice.py peak
    OPENBLAS_NUM_THREADS=1 python wick_cert/check_wick_slice.py flank
    OPENBLAS_NUM_THREADS=1 python wick_cert/check_wick_slice.py upper

The three slice commands recompute interval decisions; their stored JSON outputs alone are not used to accept mathematical inequalities. Each command took roughly one minute in the development environment.

To independently regenerate every deterministic kernel enclosure before replay:

    python wick_cert/generate_table.py peak
    python wick_cert/generate_table.py flank
    python wick_cert/generate_table.py upper

Each row took about two minutes in the development environment. Tables use exact dyadic nodes and outward dyadic endpoints; there is no floating interpolation certificate input.
