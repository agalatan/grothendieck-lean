# A Gaussian-domination inequality for a cubic chaos coupled to a linear form

## Setting
Fix the constants
  a = 699/1250,  b = 179/1250,  p = 2500/1891.

Let X₁, …, X_n be independent standard proper complex Gaussians (E X_j = 0, E|X_j|² = 1, E X_j² = 0). Let T ~ Exp(1) be independent of X.
(T plays the role of |Z|² for an extra standard complex Gaussian Z.) Put

  ℓ(T) = √T·(a + bT),  m(s) = (1/2π)∫₀^{2π} |1 + √s e^{iθ}| dθ = (2/π)(1+√s)·E_ell(4√s/(1+√s)²),

where E_ell(k) = ∫₀^{π/2}√(1 − k sin²φ) dφ, so that m is the mean modulus of a unit-circle shift.

**The cubic.** q ∈ H_{2,1}(ℂⁿ), i.e. q = Σ_{i,j,k} T_{ij,k} :X_iX_jX̄_k:, with T_{ij,k} = T_{ji,k} and
:X_iX_jX̄_k: = X_iX_jX̄_k − δ_{ik}X_j − δ_{jk}X_i. Every such q has mean zero, is orthogonal to all polynomials of degree ≤ 2, and has a law
invariant under q ↦ e^{iθ}q.

**The linear form.** r = Σ_j α_j X_j, with α ∈ ℂⁿ. Note that r may use the same coordinates as q: **no independence between q and r
is assumed.** Put ‖q‖² = E|q|² and ‖r‖² = Σ|α_j|².

**The functional.**
  Λ(q, r) = 2·E[ ℓ(T)·m( |q + (T−1)r|² / ℓ(T)² ) ] − p(‖q‖² + ‖r‖²).

**The benchmark.**
  S = sup_{v≥0} { 2·E[ ℓ(T)·m( v·E₁/ℓ(T)² ) ] − p v },
with E₁ ~ Exp(1) independent of T. This is the value of Λ when q is replaced by √v·U, with U a standard complex Gaussian (r = 0). It equals
the sup over "diffuse" cubics: n^{−1/2} Σ_j H(X_j) → U by the CLT. Numerically S = 1.3739535…, attained at v* ≈ 0.040.

## Problem
**Main target:** prove that for every n, every q ∈ H_{2,1}(ℂⁿ) and every α ∈ ℂⁿ with

  ‖q‖² ≤ 0.0463  and  ‖r‖² ≤ 0.0328,

one has
  Λ(q, r) ≤ S + 10⁻⁴.

**Ideal target:** Λ(q, r) ≤ S + 10⁻⁵ (or ≤ S) for all q, r, without the norm restrictions.
Any rigorous, dimension-free result is welcome. That includes the main target on an explicit large sub-region, for example
‖r‖² ≤ 0.01, or q with a stated cumulant bound.

## Sanity-check values (one coordinate X; q = cH(X) with H(X) = X(|X|²−2)/√2, ‖H‖ = 1; r = αX)
- c = 0.2, α = 0: Λ − S = −0.009968.
- c = 0.2, α = 0.1: Λ − S = −0.009526. Note that the coupling **raises** Λ by 4.4·10⁻⁴.
- c = 0.15, α = 0.15: −0.010582.
- c = 0, α = 0.1: −0.005543.

## Known facts you may use (all proved)
1. **Remote part.** With r = 0: Λ(q, 0) ≤ S + 10⁻⁵ for every q ∈ H_{2,1}, in every dimension.
2. **One coordinate.** If q = cH(X₁) + (an independent Gaussian part) and r = αX₁, then Λ ≤ S for all complex c, α.
3. **Gaussian q.** If q is (in the limit) a circular Gaussian independent of r, then Λ ≤ S − 0.46‖r‖² + o(‖r‖²). The A-direction has a strictly
   negative second variation at the optimum.
4. **Moments of q.** With e = ‖q‖² and κ = E|q|⁴ − 2e²: 0 ≤ κ ≤ 42e². Also κ ≤ (50/3)·e·h, where h is the largest eigenvalue of the
   derivative Gram matrix (P + Q)_{jk}, P = E[∂_{X_j}q·conj(∂_{X_k}q)], Q = E[conj(∂_{X̄_j}q)·∂_{X̄_k}q]. Moreover
   E|q| ≤ 0.9707‖q‖.
5. **First variation.** At r = 0 the derivative in the direction r equals 2Re E[r̄·Φ(q)], with
   Φ(w) = 2E_T[(T−1)·m′(|w|²/ℓ(T)²)·w/ℓ(T)]. Since r is a linear form, only the first-chaos projection P₁Φ(q) matters (the "content" of q). It
   vanishes when q is Gaussian and is generated by the non-linearity of Φ.

## Routes known to FAIL
- **Content ≤ f(kurtosis), slack ≥ g(kurtosis).** Splitting the problem through fourth moments alone fails: the content is third order in the
  non-Gaussianity, while the slack S − Λ(q, 0) is only second order, and the moment-only bounds cross. Any proof must keep finer structure
  of q than its fourth moment.
- **Fibrewise Gaussian domination.** For a fixed T, the X-expectation of ℓm(|q + (T−1)r|²/ℓ²) is *not* maximised by Gaussian q. The average over
  T is essential.
- **Pointwise concavity.** m(s) is not concave in s, so Jensen in |q + (T−1)r|² is false; its least concave majorant loses too much.
- **Monotonicity along the CLT** (replacing q by (q(X) + q(X′))/√2) is false for related functionals.
- Small-coupling perturbation alone reaches only ‖r‖ ≲ 0.03. The difficulty is genuinely at moderate ‖r‖ (0.03 to 0.18) together with
  non-Gaussian, coupled q.

## Numerical evidence (not proof)
On all tested families (Wick monomials, mixtures with diffuse parts, coupled two-coordinate cubics), the gain from adding r is at most about
0.4 of the slack S − Λ(q, 0). So the target appears true with margin.
