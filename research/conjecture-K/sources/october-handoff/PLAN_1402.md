## The logical chain (what implies 1.402)

Witness T = P_{1,0} − ε P_{2,1}; K_G^C ≥ 1/‖T‖_{∞→1}; target ‖T‖ ≤ 500/701 = 0.71326676.

1. **Row reduction [P]** (handoff Prop. `prop:row`, ch7). For unimodular f, g with t = ‖Ph‖ ∈ [0, 1], and every profile
   (ℓ, β): Re⟨f, Tg⟩ ≤ t² − 2ℓt + 2β²/ε + Λ_{ℓ,β}(G), where G = εQk ∈ H_{2,1}. So
   ‖T‖ ≤ sup_t min_k [ t² − 2ℓ_k t + 2β_k²/ε + sup_G Λ_k(G) ].
2. **Per-profile K_η.** At profile k one needs sup_G Λ_k(G) ≤ S(ℓ_k, β_k) + η_k. The allowance under exact K, with the
   profile re-optimised per row (float, ε = 0.7564) [F]:
   t = 0.845: 1.32e-4 (the minimum); 0.84/0.85: 1.5–1.6e-4; |t − 0.845| ≥ 0.015: ≥ 3.4e-4; outside [0.82, 0.87]: ≥ 7e-4;
   t = 0.75: 7.7e-3; t = 0.70: 1.6e-2. The degree-3 ceiling is 1.402258 at ε = 0.7564 (1.402166 at ε = 0.75).
3. **Small t.** The crude row (ℓ, β) = (0, 0) needs ερ² ≤ 500/701, where ρ = sup E|q|/‖q‖₂ over H_{2,1}.
   The older Lean radius ρ = 0.973612 fails this test at ε = 0.7564. The newer external bound ρ ≤ 0.95133 (scalar-Stein, 21 Oct, ch62 §real-stein-radius; IDE-replayed) covers t ≤ 0.1694; ρ ≤ 0.96018 with C6 = 50. 4. **Assembly.** Certified upper bounds for S(ℓ_k, β_k) (closed forms: Rice mean, erfc recurrence), the parabola cover in
   t, and exact rational arithmetic. This is mechanical once 2–3 are theorems.
