## 2. The correction lemma

| # | statement | scope | status | where |

| 2.1 | **Theorem.** Let ν ≥ 0, d₂, d₃ > ν, R ≥ 0 and 0 ≤ γ ≤ γ\*(R). For all L, p ∈ ℂ with \|L\| ≤ R: Φ_d(L + p, L − p) − (γ/16)·(4Re(pL̄) − c₀ − c₁\|L\|²)² ≥ Ψ_ν(L + p, L − p).
