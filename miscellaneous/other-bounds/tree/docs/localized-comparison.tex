\begin{theorem}[Selected-spectrum comparison]
Let $G,X$ lie in a Gaussian $L^2$ space with orthogonal chaos blocks $P_p$.
Let $S$ be a finite set of blocks and write $G-X=\sum_r D_r$. Suppose that
$D_r$ is supported on a specified band $B_r$ and $\|D_r\|_2\le e_r$,
with $A_r,e_r\ge0$. Let $0\le w_p\le1$ be coefficient costs.
If $A_r^2\ge\sum_{p\in S\cap B_r}w_p^2\|P_pX\|_2^2$, then
\[
 \sum_{p\in S}w_p\left|\|P_pG\|_2^2-\|P_pX\|_2^2\right|
 \le 2\sum_r A_re_r+\left(\sum_r e_r\right)^2.
\]
The choice $w_p=1$ recovers the unweighted comparison. The bands may overlap. The same error components are retained throughout.
\end{theorem}
\begin{proof}
For vectors $x,y$ in a normed space,
$|\|y\|^2-\|x\|^2|\le2\|x\|\|y-x\|+\|y-x\|^2$.
Apply this to each block. The linear part is bounded by
\[
 \sum_p w_p\|P_pX\|\|P_p(G-X)\|
 \le\sum_r\sum_{p\in S\cap B_r}w_p\|P_pX\|\|P_pD_r\|
 \le\sum_r A_re_r,
\]
by Cauchy--Schwarz and orthogonality. The quadratic part is at most
$\|G-X\|_2^2\le(\sum_r e_r)^2$, since $w_p\le1$.
\end{proof}
